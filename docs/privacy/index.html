THE SHORT VERSION

Privacy & Enquiry Handling

This is a demonstration prepared for the business owner, not the company’s final legal privacy policy. Do not treat it as a substitute for review by the owner.

In the GitHub Pages preview, form content stays in the visitor’s browser until the visitor opens a messaging app; GitHub Pages does not receive form submissions. The visitor must tap Send in the messaging app.

On Node.js hosting, the bundled handler saves form submissions to a private local JSON Lines file and provides an owner-only inbox. The owner must set an admin password and choose their retention and access policy before launch.
